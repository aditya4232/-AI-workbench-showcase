## 3. Design System & Visual Identity

### Design Philosophy
**"Clean Engineering Portfolio"** — Inspired by top-tier engineering resumes and Apple/Hashnode minimalism.

**Anti-patterns (AVOID):**
- Gradient-heavy backgrounds
- Neon glow effects
- Robot/AI cliche imagery (circuit boards, brains, etc.)
- Holographic/glassmorphism overload
- Animated particle backgrounds

**Design Patterns (USE):**
- Clean white / off-white backgrounds with dark mode support
- Sharp typography hierarchy (scale: xs, sm, base, lg, xl, 2xl, 3xl, 4xl)
- Subtle border-based cards (no heavy shadows)
- Monochromatic color palette with 1-2 accent colors
- Generous whitespace (p-8 to p-16 sections)
- Grid-based layouts for project cards

### Color Palette (Dark mode default)

```
--background: #0a0a0b        (very dark gray, not pure black)
--foreground: #fafafa
--card: #18181b
--card-foreground: #fafafa
--accent: #3b82f6            (blue-500, restrained)
--accent-foreground: #ffffff
--muted: #27272a
--muted-foreground: #a1a1aa
--border: #27272a
--ring: #3b82f6
```

### Typography
- **Headings:** Inter, 700 weight
- **Body:** Inter, 400 weight
- **Code/Tech tags:** JetBrains Mono, 400 weight
- **Scale:** 14px (small) → 64px (hero heading)

### Component Style
- Cards: `rounded-lg border border-[--border] bg-[--card] p-6`
- Buttons: `rounded-md bg-[--accent] px-4 py-2 text-sm font-medium`
- Tags: `rounded-full px-3 py-1 text-xs font-mono border`
- Section spacing: `py-24` (96px vertical padding per section)

## 11. Edge Cases & Considerations

- **No README content:** Some repos (AI-Customer-Support-Ticket-Classifier, Talentradar-System, intraday-stock-analyzer) lack READMEs. For these, use repo name/detected language + description from GitHub API as placeholder content.
- **Streamlit app accessibility:** The live Streamlit app may have API key requirements. The showcase will link to the live app with a note about bringing your own API key.
- **Responsive breakpoints:** All components tested at 320px (mobile), 768px (tablet), 1024px+ (desktop).
- **Performance budget:** < 100KB JS per page, < 90 Lighthouse score, < 2s LCP.
- **No AI-generated imagery:** Use only clean SVG icons (Lucide) and text-based design elements.
- **Existing site consistency:** The showcase should feel complementary to, but distinct from, the terminal-themed adityacuz.dev. Use a clean/minimal aesthetic.
